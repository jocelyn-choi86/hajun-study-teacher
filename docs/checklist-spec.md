# 하준이 공부 체크 — 화면 기획서

> 참고 구현: `checklist/index.html` (claude.ai 아티팩트 버전). 이 문서만 보고 다른 환경(Supabase + 웹 호스팅 등)에서 같은 화면을 다시 만들 수 있도록 정리함.
> 초기 할 일 데이터: `data/weekly-plan.md` (v3)

## 1. 목적

- 초등 6학년 하준이가 **요일별 할 일을 보고 하나씩 체크**하는 화면.
- 부모는 같은 화면에서 진행 상황을 확인하고, **할 일 목록을 편집**한다.
- 휴대폰·태블릿 세로 화면이 기본. PC에서도 가운데 한 줄(최대 640px)로 보인다.

## 2. 사용자와 권한

| 사용자 | 체크·숙제 메모 | 할 일 편집 | 비고 |
|---|---|---|---|
| 하준 | O | X | "할 일 편집" 버튼이 보이지 않음 |
| 부모 | O | O | 여러 명 가능 |
| 그 외 | X | X | 로그인하지 않으면 데이터 접근 불가 |

권한은 화면에서 버튼을 숨기는 것만으로 끝내지 말고 **서버(DB 규칙)에서도 막는다.**

## 3. 화면 구성 — 체크리스트 (기본 화면)

위에서 아래 순서.

### 3-1. 헤더
- 왼쪽: 제목 **"하준이 공부 체크"**
- 오른쪽:
  - 주 이동: `‹` 버튼, 기간 표시(예: `11/2 – 11/8`, 월~일), `›` 버튼
  - **"할 일 편집"** 버튼 (부모에게만 보임) → 편집 화면으로 이동
- 좁은 화면에서는 줄바꿈 허용.

### 3-2. 요일 탭 (7칸 가로 한 줄)
- 각 칸: 요일(월~일), 날짜(`11/3`), 그날 진행률 막대(완료 개수 / 전체 개수).
- **오늘** 칸: 날짜를 파란색 굵게.
- **선택된** 칸: 파란 테두리.
- **일요일**: 요일 글자를 빨간색.
- 첫 진입 시 오늘 요일이 선택됨. 칸을 누르면 아래 카드가 그 요일로 바뀜.

### 3-3. 요일 카드
**카드 머리**
- 제목: `화요일`
- 요약 한 줄: `0 / 9 완료 · 0분 / 약 195분 · 공부 시간 180분`
  - 완료 개수 / 전체 개수
  - 완료한 할 일의 예상 시간 합 / 전체 예상 시간 합
  - 그날 공부 가능 시간 (토요일은 "180분 이상", 일요일은 "가족 시간 · 저녁 보강만")
- 진행률 막대 (완료 개수 기준, 초록색)
- 고정 일정 칩: `학교 ~14:30`, `수영 18:00–19:00` 등 (테두리만 있는 둥근 칩)

**할 일 목록** (한 줄에 하나, 줄 사이 구분선)

| 위치 | 내용 |
|---|---|
| 왼쪽 | 체크박스 (둥근 사각형, 체크하면 초록 배경 + 흰 체크) |
| 가운데 1줄 | 과목 태그(색 테두리 작은 라벨) + 할 일 이름 |
| 가운데 2줄 | 메모 (교재명, 주의할 점) — 있을 때만, 회색 작은 글씨 |
| 가운데 3줄 | 숙제 메모 입력칸 — "숙제 칸" 설정된 할 일만 (점선 테두리, 예: "3800제 p.24–27") |
| 오른쪽 | 예상 시간 `10분` |

- 체크하면 이름에 초록 취소선, 글자 회색.
- 이름이나 태그를 눌러도 체크된다.

**"매일" 구역**
- 회색 띠 제목 "매일" 아래 `책 읽기`(하루 마무리) 고정 1줄. 시간 표시 없음.

**완료 메시지**
- 그날 할 일을 모두 체크하면 카드 아래에 "오늘 할 일 끝! 수고했어, 하준아." 표시.

### 3-4. 하단
- 과목 색 범례: 국어 · 수학 · 영어 · 사회 · 과학 · 학교·기본
- 저장 상태 한 줄 (예: "체크하면 자동으로 저장돼요.", "저장하지 못했어요. 잠시 뒤 다시 체크해 주세요.")

## 4. 화면 구성 — 할 일 편집 (부모 전용)

- 헤더 제목이 "할 일 편집"으로 바뀌고, 버튼은 "체크리스트로". 주 이동은 숨김.
- 요일 탭: 날짜 대신 할 일 개수(`9개`) 표시.
- 선택한 요일에 대해:
  - 하루 공부 가능 시간(분) 숫자 입력
  - 고정 일정: 여러 줄 입력 (한 줄에 하나)
  - 할 일마다: 과목 선택, 이름, 예상 시간(분), 메모, "숙제 메모 칸 보이기" 체크, 위로/아래로, 삭제
  - "+ 할 일 추가"
- 하단 버튼:
  - **저장**: 변경이 있을 때만 활성. 이름이 빈 할 일은 저장 시 제외.
  - **되돌리기**: 마지막 저장 상태로.
  - **처음 배치안으로**: 누르면 화면 안에서 "바꾸기 / 취소" 확인 후 기본 배치안으로 (저장해야 반영).
- 저장하지 않은 변경이 있으면 "저장하지 않은 변경이 있어요" 표시.

## 5. 동작 규칙

- **자동 저장**: 체크·숙제 메모는 입력 후 약 0.4초 뒤 자동 저장 (연속 입력은 한 번으로 묶음).
- **실시간 반영**: 다른 기기에서 체크하면 열려 있는 화면에도 반영. 숙제 메모를 입력하는 중에는 입력칸을 덮어쓰지 않는다.
- **주 단위 기록**: 체크는 주(월요일 날짜 기준)별로 따로 저장. 지난주로 넘기면 지난주 기록이 보인다.
- **할 일 ID**: 체크 기록은 할 일 ID로 연결. 이름을 고쳐도 체크가 유지되고, 삭제한 할 일의 체크는 무시.
- **오프라인/연결 실패**: 10초 안에 서버 응답이 없으면 "저장소에 아직 연결하지 못했어요" 안내.
- **날짜 기준**: 기기 현지 시간(한국 시간)으로 오늘·이번 주 계산.

## 6. 데이터 구조 (Supabase 예시)

```sql
-- 가족 구성원과 역할
create table members (
  user_id uuid primary key references auth.users,
  role text not null check (role in ('parent','child')),
  name text
);

-- 요일별 할 일 목록 (한 행, 부모만 수정)
create table plan (
  id int primary key default 1,
  days jsonb not null,          -- 아래 형식
  updated_at timestamptz default now()
);

-- 주별 체크 기록
create table weeks (
  week_start date primary key,  -- 그 주 월요일
  checks jsonb not null default '{}',  -- {"tue": {"pilsa": true, "calc": true}}
  hw jsonb not null default '{}',      -- {"wed_enghw": "3800제 p.24-27"}
  updated_at timestamptz default now()
);
```

`plan.days` 형식:

```json
{
  "tue": {
    "label": "화", "cap": 180,
    "events": ["학교 ~14:30", "수영 18:00–19:00"],
    "tasks": [
      {"id": "pilsa", "tag": "기본", "name": "필사 · 한자", "min": 10, "note": ""},
      {"id": "enghw", "tag": "영어", "name": "과외 숙제 (금요일 수업)", "min": 30, "note": "", "hw": true}
    ]
  }
}
```

**접근 규칙 (RLS)**
- `members`에 있는 사용자만 `plan`, `weeks` 읽기 가능.
- `weeks` 쓰기: parent, child 모두.
- `plan` 쓰기: parent만.
- 실시간 반영은 Supabase Realtime으로 `weeks`, `plan` 변경 구독.

## 8. 이번 범위에서 제외

- 알림·푸시
- 통계·주간 리포트 화면
- 할 일별 실제 소요 시간 기록
- 정답률·채점 기록

## 9. 완료 기준

1. 하준 계정으로 로그인 → 오늘 요일 할 일이 보이고, 체크하면 새로고침 후에도 유지된다.
2. 부모 계정 화면에서 하준이 체크가 실시간으로 보인다.
3. 하준 계정에는 "할 일 편집" 버튼이 없고, 직접 `plan`에 쓰기를 시도해도 거부된다.
4. 부모가 할 일을 추가·수정·순서 변경·삭제하고 저장하면 하준 화면에 반영된다.
5. 숙제 메모를 입력하고 다른 기기에서 보면 같은 내용이 보인다.
6. 지난주로 넘기면 지난주 체크 기록이 보인다.
7. 휴대폰 세로 화면과 다크 모드에서 글자가 잘리거나 겹치지 않는다.
